# ezway_business_website

Ezway marketing site (Next.js App Router + Tailwind).

## App location

The Next.js app lives in [`web/`](./web).

```bash
cd web
npm install
npm run dev
```

## Vercel

- **Root Directory:** `web`
- **Framework:** Next.js
- **Build:** `npm run build`
- **No env vars required** for the static marketing site
